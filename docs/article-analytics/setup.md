# GA4 の初期設定と数字の見方

[記事の読まれ方評価の手順](README.md) で使う GA4 の設定と、評価日に数字を取る方法です。初期設定は一度だけ行います。

GA4 と Zenn の画面の名前は変わることがあります。ここに書いた名前の項目が見つからなければ、GA4 のヘルプで現在の名前を確かめ、この文書を直します。Zenn のアカウント設定画面は、ログインが必要なため調査では実物を確認できていません。

## 初期設定

### GA4 のプロパティを作る

Google アナリティクスの管理画面で、Zenn 用のプロパティを新しく作り、ウェブのデータストリームを追加します。URL は `https://zenn.dev` にします。作成後に表示される `G-` で始まる測定 ID を控えます。

### データの保持期間を 14 か月にする

管理画面の「データの収集と修正」→「データ保持」で、保持期間を 14 か月に変えます。初期値の 2 か月のままだと、探索レポートで 12 週後の評価や、過去との比較ができなくなるからです。

### Zenn に測定 ID を登録する

Zenn の「アカウント設定」で、控えた測定 ID を登録します。登録すると、`https://zenn.dev/ユーザー名` で始まるページの表示が GA4 に送られます（[Zenn のリリース](https://info.zenn.dev/2020-11-19)）。

### praha の記事が計測されるか確かめる

公開済みの記事はすべて Publication「praha」に紐づいています。Zenn のコードを読む限り、Publication の記事の表示も著者個人の GA4 に送られますが、実際には確かめていません。

GA4 の「レポート」→「リアルタイム」を開いたまま、ログアウトした別のブラウザで自分の praha の記事を開きます。数十秒以内にリアルタイムの画面に表示が出れば計測できています。Zenn は表示から 1 秒ほど待ってから送るので、開いてすぐ閉じると数えられません。

出なかった場合は、praha の管理者に Publication 側の GA4 のデータを見せてもらえないか相談します。

完了の目安は、自分の praha の記事を開いたときの表示がリアルタイムの画面に出ていることです。

## 数字の見方

評価日ごとに、対象の記事について次の数字を取ります。期間は、1 週後なら公開日から 7 日間、4 週後と 12 週後なら直近 28 日間にします。

閲覧数は、「レポート」→「エンゲージメント」→「ページとスクリーン」で、記事のページパス（`/ユーザー名/articles/<slug>`）の行の「表示回数」を見ます。

検索流入と流入経路ごとの内訳は、「探索」で自由形式のレポートを作って見ます。行に「ランディング ページ」、列に「セッションのデフォルト チャネル グループ」、値に「セッション」を置きます。一度作れば保存して使い回せます。対象の記事の行で、「Organic Search」の列が検索流入です。流入経路は、「Organic Search」を検索、「Organic Social」を SNS、「Referral」のうち参照元が `zenn.dev` のものを Zenn 内として数えます。

Zenn 内を回遊して来た読者が GA4 でどの参照元として記録されるかは、調査では確認できていません。最初の評価のときに、Zenn 内からの流入が「Referral」と「Direct」のどちらに入っているかを確かめ、この段落を直します。
